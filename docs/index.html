How to install

  1. Tap Download for Android above. Chrome may warn "this type of file can harm your device" — tap Download anyway (it's safe, just not from the Play Store).
  2. Open the downloaded wavelength.apk (from the notification or your Downloads).
  3. If prompted, allow "Install unknown apps" for Chrome, then tap Install.
  4. Open Wavelength and sign up — you're in. 🎧

📱 This is an Android app (.apk). iPhone isn't supported via this download. If installation is blocked, go to Settings → Apps → Special access → Install unknown apps → Chrome → Allow.
